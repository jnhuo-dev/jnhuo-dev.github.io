기존에는 Revit에서 검토 객체를 클라우드 마크 등으로 표시하고, 표시된 객체를 찾아 각자 PPT 검토보고서를 쓴 뒤, 그걸 모아 엑셀 리스트를 다시 만들었다. 검토 객체를 관리하기 어렵고 따로 표시해야 해서 휴먼 에러가 나기 쉬운 방식이었다.

바꾼 방식에서는 검토사항이 생긴 부재에 검토사항, 검토차수, 참고 도면번호 같은 매개변수만 입력한다. 나머지는 알고리즘이 처리한다.

1. 매개변수를 조합해 검토보고서 리스트(엑셀)를 만든다. 조건문으로 검토 유형과 중요도도 표시한다.
2. 검토요소마다 검토차수, 매개변수 값, 패밀리 이름, 레벨, ID가 들어간 이름으로 3D 뷰를 만든다.
3. 3D 뷰를 이미지로 내보낸다. 템플릿을 적용해 검토 요소만 빨간색으로 표시할 수 있다.
4. Python(pandas)으로 만든 실행파일이 텍스트와 이미지를 모아 보고서 양식에 맞춘 PPT를 한 번에 만든다.

## 추가 프로그램

- **E2P** (Excel to PPT) — Dynamo로 뽑은 엑셀 데이터로 검토보고서 PPT 생성
- **P2E** (PPT to Excel) — 수정을 마친 검토보고서 PPT에서 리스트 엑셀 생성
- **CSN** — 검토사항 번호가 바뀔 때마다 반복하던 수정 작업을 줄이려고 번호를 자동으로 다시 매김

이 흐름을 실무에서 쓰기 쉽게 Revit 안으로 옮긴 것이 [JHSLab Add-in](#/projects/jhslab-addin)이다.
