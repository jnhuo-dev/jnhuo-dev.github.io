자동화 방식의 검토보고서 작성([BIM 검토보고서 자동화](#/projects/bim-report-automation))을 실무에서 더 쉽게 쓸 수 있도록 만든 Revit 애드인. 모두 C#과 Revit API로 작성했고, 입력이 많은 기능에는 WinForms 창을 붙였다. 기능은 리본 메뉴에서 네 그룹으로 나눴다.

## 모델링

- **레벨 값 복사·붙여넣기** — 처음 선택한 요소의 레벨 관련 매개변수를 이후 선택한 요소들에 적용
- **전경/배경 토글** — 삽입된 DWG의 전경/배경 설정을 스위치처럼 전환
- **밝음/어두움 토글** — Revit UI 테마 전환 (2024 버전)

## 검사

- **그리드 간격 검사** — 같은 방향 그리드 사이 간격이 정수로 떨어지지 않는 곳을 찾음
- **빈 태그 삭제** — 현재 뷰에서 값이 비어 있는 태그를 찾아 삭제
- **조적벽체 검토** — 재료명에 '조적'이 들어간 벽 중 두께의 36배를 넘는 벽을 찾아 ID를 엑셀로 내보냄
- **블록벽체 검토** — 콘크리트블록 벽의 두께(4·6·8인치)별 기준 높이(3.6·5.4·6.8m)를 넘는 벽의 ID를 엑셀로 내보냄

## 검토보고서 자동화

- **검토 매개변수 입력창**, **검토유형 선택** (상이·간섭·누락·시공성·검토요청)
- **그래픽 재지정** — 선택한 요소를 빨간색으로 표시하거나 기본값으로 되돌림
- **검토 값 복사·붙여넣기** — 첫 요소의 검토유형·검토의견을 다른 요소에 적용
- **검토번호 입력** — '요소ID'와 '도서검토번호'가 적힌 엑셀을 읽어 해당 요소에 번호 입력

## 조달청

- **실ID 생성기** — 조달청 「시설사업 BIM 적용지침서 v2.1」 기준에 맞춰 '시설분류' 값으로 실ID를 자동 생성하고, 값이 빠진 룸이 있으면 알려줌
